# Midnight at Morty's

A first-person survival horror game built in Unreal Engine 5.4, co-developed with Kieran
as a two-person university team project (2025), with additional art assets contributed by
Gian.

## What's implemented

- True first-person movement and an interact system for doors, keys and item pickups.
- An AI antagonist, Morty, driven by a Behavior Tree/Blackboard that patrols and pursues
  the player.
- A doll-collection and offering mechanic (`BP_DollOffering`, `W_OfferDolls`).
- A notes/noteboard system for environmental clues.
- Jump-scare triggers and audio cues, plus an in-level arcade machine prop.
- A retro PS1-style shader and post-processing pass for the game's visual identity.

## Tech stack

Unreal Engine 5.4, Blueprints.

## Getting started

Open `MidnightAtMortys/MidnightAtMortys.uproject` in Unreal Engine 5.4.
